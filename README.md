# NOVA

NOVA is the home of the upcoming browser-based online game.

## Project status

The repository infrastructure is being prepared. Game implementation has not started.

## Planned platform

- GitHub for source control, pull requests, releases, automation, and deployment.
- GitHub Actions for CI and deployment workflows.
- GitHub Pages as the initial static hosting target.
- Supabase project `NOVA` for backend services when they are needed.

## Security

Never commit secrets, service-role keys, or private credentials. Browser clients must use only a publishable Supabase key, with database access protected by Row Level Security (RLS).

## Current scope

Infrastructure setup only. The game framework, application architecture, and database schema remain undecided.
